> **ASTRIX AI** is an intelligent, high-precision conversational AI assistant powered by Google Gemini and local LLMs, wrapped in a futuristic cyberpunk glassmorphism interface. Designed and founded by **Om Kalmegh**.

---

## 🌟 Key Features

- **⚡ Direct Gemini API Integration**: Built-in support for `gemini-3.6-flash`, `gemini-3.8-flash`, `gemini-flash-latest`, and `gemini-pro-latest`.
- **🔌 Multi-Provider Support**: Seamlessly switch between Google AI Studio Gemini API and local LLM endpoints (Ollama / OpenAI-compatible local servers at `http://localhost:11434/v1`).
- **🔊 Voice Synthesis (TTS)**: Built-in Text-to-Speech audio reader for hands-free listening to responses.
- **📋 Developer Tools**: One-click code snippet copying, structured markdown rendering, and clean chat bubbles.
- **🔒 Privacy-First Architecture**: Your API keys and chat histories are stored strictly in your browser's `localStorage`—no intermediate servers or data logging.
- **🎨 Modern Glassmorphic UI**: Ambient cyan/violet glow effects, fluid micro-interactions, responsive sidebar, and modal settings.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Semantic Markup
- **Styling**: Vanilla CSS3 (Custom CSS Properties, Glassmorphism, Neon Glow effects, Flexbox & Grid)
- **Logic**: Vanilla Modern JavaScript (Async/Await, Web Speech API, Fetch API, LocalStorage API)
- **AI Engine**: Google Gemini REST API & Local LLM endpoints

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/omkalmegh4-gif/astrix-ai.git
cd astrix-ai
```

### 2. Run the application
Open `ai.html` or `index.html` directly in any modern web browser, or serve it with a local server:
```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

### 3. Configure your API Key
1. Get a free Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Click the **Settings (⚙️)** button in ASTRIX AI.
3. Paste your API key, select your preferred model, and click **Save & Connect**.
